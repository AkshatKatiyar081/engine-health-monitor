# Data

NASA C-MAPSS turbofan degradation data (public domain, NASA Prognostics Center of Excellence).
Not stored here. On Kaggle, attach any C-MAPSS dataset (the notebooks find the `train_FD00x.txt`, `test_FD00x.txt` and `RUL_FD00x.txt` files automatically). Locally, put the raw files in `DataSet/` and run `python scripts/convert_to_csv.py` to get headed CSVs in `data/csv/`.
